# Vibe

### Fast, private transcription desktop app

Vibe is a lightweight desktop transcription app that runs Whisper locally for lightning-fast, completely private audio-to-text conversion. Available for Windows and macOS with a clean, minimal interface.

<br>

---

## Features

| | |
|:---|:---|
| **Whisper Local** | All transcription runs on your device — nothing sent to any server |
| **Fast Processing** | Optimized inference engine delivers transcripts in near real-time |
| **Multiple Formats** | Export as plain text, SRT, VTT, or structured JSON |
| **Simple Interface** | Drag-and-drop files or record directly from your microphone |
